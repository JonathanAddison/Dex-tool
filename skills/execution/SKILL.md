# دستورالعمل اجرا

1. برای تست سریع از `python_execute` یا `node_execute` استفاده کن.
2. برای دستورات shell از `bash_execute` استفاده کن.
3. برای اجرای تست‌ها از `run_tests` با دستور مناسب استفاده کن.
4. خروجی‌ها را تحلیل کن و در صورت خطا، اصلاحات لازم را انجام بده.
