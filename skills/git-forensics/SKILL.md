# دستورالعمل تحلیل Git

1. با `git_status` وضعیت فعلی را ببین.
2. با `git_log` تاریخچه‌ی اخیر را مرور کن.
3. با `git_blame` روی فایل‌های مشکوک، نویسنده‌ی خطوط را پیدا کن.
4. با `git_diff` تغییرات اخیر را بررسی کن.
5. در پاسخ نهایی، کامیت‌های مرتبط را با هش ذکر کن.
